# NEMO Live Kora — تدقيق اقتران النتائج بصاحبها (انعكاس «1 - 0») وإصلاح شامل — 2026-10-17

## النتيجة التنفيذية

**الشكوى المُدقَّقة:** «بعض المباريات تعرض النتيجة معكوسة (1 - 0 بدل 0 - 1)».

**الحقيقة المثبتة بعد التدقيق:** مسار الحفظ بأكمله — نموذج الإدارة ← `POST/PATCH /api/admin/matches` ←
وثيقة `manual-content.json` ← المخزن الدائم ← الدمج والتثبيت (overrides) ← المحوّلات ← الكرون — **سليم
ربطيًا**: `score.home` دائمًا مع `homeTeam` و`score.away` دائمًا مع `awayTeam`، بمفاتيح لا بمواقع نصية.
العلة كانت **عرضية حصراً**: شارة النتيجة في بطاقة المباريات كانت مغلّفة بـ`dir="ltr"` لتثبيت الفاصل
اللاتيني، فاصطكّ ترتيب الأرقام مع اتجاه الأعمدة RTL — رقم الفريق الأول جلس ملاصقًا لعمود الفريق الثاني،
فقُرئت «1 - 0» للزائر وكأنها «0 - 1». أي أنها **كانت خدعة بصرية فقط لا فساد تخزين**؛ ولم تُحفظ أي نتيجة
مخزّنة معكوسة قط (انظر دليل التدقيق أدناه).

**ما نُفّذ:** مصدر وحيد للعرض الاقتراني `lib/matches/score-view.ts` + مكوّن `components/MatchScoreView.tsx`؛
كل رقم في عنصر مستقل يحمل هوية صاحبه (`data-side` + `data-team-id` + `aria-label`)، بترتيب DOM منطقي
ثابت [الأول، الفاصل، الثاني] يسير مع اتجاه الصفحة **بلا أي `dir` مفروض**. حُوّلت إليه كل أسطح العرض:
بطاقة الرئيسية/الجدول، صفحة الهبوط، صفحة البث، تفاصيل المصدر، جدول الإدارة، وصفحة الإدارة (سطر
«النتيجة المعروضة» + تسميات حقول النموذج باسم الفريقين)، وبطاقة OG. أُضيف حارس بنيوي يمنع رجوع نمط
«النص المركّب + dir» في أي سطح عرض.

**الحالة:** اختبارات المستودع **361/361** ناجحة (منها 9 جديدة لهذا التدقيق)؛ lint/typecheck/build نظيفة؛
تدقيق القيم المخزّنة مقابل المرجع الموثوق: **صفر انعكاسات**. لم يُنشر شيء إلى الإنتاج من هذه الجلسة.

## مصفوفة النتائج المفروضة — والنتيجة في كل سطح

لكل حالة خُزّن `score.home=A` مع الفريق الأول و`score.away=B` مع الثاني، ثم فُحصت الصفحات بعد **إعادة
تحميل كاملة** (GET مستقل، وبعد إعادة إقلاع الخادم أيضًا):

| # | الحالة | المخزن | الرئيسية | جدول /matches | صفحة الهبوط | صفحة البث /live |
|---|--------|--------|----------|---------------|--------------|-----------------|
| 1 | إضافة 1-0 (فوز الأول) | `home:1, away:0` | ✓ الرقم 1 بعد اسم الأول في التدفق، 1 قبل اسم الثاني | ✓ | ✓ | ✓ |
| 2 | تعديل PATCH إلى 0-1 | `home:0, away:1` | ✓ لا انعكاس ولا نسخة ثانية | ✓ | ✓ | ✓ |
| 3 | تعديل إلى 2-2 | `home:2, away:2` | ✓ | ✓ | ✓ | ✓ |
| 4 | تعديل إلى 4-1 | `home:4, away:1` | ✓ | ✓ | ✓ | ✓ |
| 5 | تحديث مباراة مباشرة (live ‏66′، 3-1) | `home:3, away:1` + الدقيقة | ✓ | ✓ | ✓ «جارية» + 66′ | ✓ |
| 6 | تثبيت يدوي override ‏4-1 مرتان متتاليتان | لا قلب مزدوج (idempotent) | — | جدول الإدارة ✓ | ✓ | — |

التحقق بنيوي لا نصي: يُشترط في كل صفحة أن عنصر `data-side="home"` يحمل `data-team-id` الخاص بالفريق
الأول وقيمته رقم الأول، و`data-side="away"` كذلك للثاني، وألّا يظهر `dir=` على أي حاوية نتيجة.

## الإصلاح المطبَّق — قواعد العقد

1. **الربط بالمفاتيح حصرًا** — كل طبقة تحمل `score.home`/`score.away` كمفاتيح مرتبطة بـ`homeTeam`/`awayTeam`
   (`buildManualMatchFromForm`، `normalizeManualDocument`، `buildMatchRecordFromManual`، الدمج والتثبيت).
   جولة JSON كاملة (تسلسل ← إعادة تطبيع) مختبَرة: الأرقام لا تعبر إلى المفتاح الآخر ولا تتبدل مع الأسماء.
2. **عناصر أرقام منفصلة بمعرّفات الفريق** — `MatchScoreView` يبني من `buildMatchScoreView({score, status,
   homeTeam, awayTeam})` ثلاثة عناصر بترتيب DOM [الأول، الفاصل، الثاني]؛ لا سرد نصي `${home} : ${away}`
   في أي مكوّن عرض بعد اليوم (حارس فحص مصادر يرفض القالب اليدوي و`kl-score-badge[^>]*dir=`).
3. **الأول يظهر أولًا وفق سياق RTL الطبيعي** — لأن الأرقام صارت عناصر مستقلة في نفس تدفق الصفحة، صار رقم
   الفريق الأول يوازي عمود الفريق الأول يمينًا تلقائيًا؛ الفاصل المحايد (`:`/`-`) ينطبق عليه bidi كما هو
   متفق عليه في كل البطاقات منذ إطلاق التصميم.
4. **الحالات** — `not_started/postponed/cancelled` تُحجب أرقامها بقاعدة واحدة مشتركة (`formatScoreDisplay`
   في `lib/cairo-time.ts` هي بوابة القاعدة ذاتها؛ «—» بدل «0 - 0»)، والحالات المستقبلية «لم تبدأ بعد»
   تعرض VS حيث يلزم (صفحة البث).
5. **منع القلب المزدوج** — لا يوجد أي `dir` مصحِّح في أي مكان بعد الإصلاح؛ من يغيّر اتجاه العمود الآن لا
   يغيّر اتجاه الرقم لأنه ملتصق به في التدفق. التثبيت اليدوي فوق سجل مصدر يطبَّق بالمفاتيح وتكراره
   idempotent (مختبَر: قفل 4-1 فوق مصدر 1-0 مرّتين).
